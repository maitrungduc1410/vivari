OpenContainer · Phase 2 — Path B (real Node lib/)

The kernel + Rust/Wasm VFS run in a dedicated kernel worker; process workers are spawned nested under it. Programs run Node's REAL, unmodified lib/path.js and lib/buffer.js (v24.18.0) over our internalBinding layer. The in-memory HTTP server is previewed via a Service Worker — try GET /api/buffer in the preview. The VFS is mirrored to OPFS, so files survive a reload — try GET /api/persist, then reload. Append ?reset to the URL to clear the persisted filesystem.
